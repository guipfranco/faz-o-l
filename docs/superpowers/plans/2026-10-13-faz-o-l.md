# Faz o L: Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar um match-3 jogável no Chrome (duplo clique em `index.html`, offline) em que aliados do Lula falam frases reais ao dar match, obstáculos do governo anterior atrapalham, e os 27 estados do Brasil vão melhorando no mapa conforme o jogador vence fases.

**Architecture:** Toda a regra do jogo vive em `src/logica/` como funções puras sobre um objeto de estado (sem Phaser, sem DOM), testadas com `node --test`. Uma cena Phaser 3 só renderiza o estado e anima a lista de eventos que a lógica devolve a cada jogada. O mapa é SVG em uma camada HTML por cima do canvas; a voz é um módulo próprio com fallback mp3, depois voz sintetizada, depois só balão. Dados editáveis (frases, estados, fases) ficam em `dados/`.

**Tech Stack:** JavaScript sem build (scripts clássicos com namespace global `FazOL`), Phaser 3.80.1 embutido em `lib/`, Node 24 só para testes e ferramentas de geração (mapa e arte), `localStorage` para progresso.

**Spec:** `docs/superpowers/specs/2026-10-13-faz-o-l-design.md`

## Global Constraints

- Tudo roda via `file://`: **nenhum `fetch`, XHR ou `<script type="module">`**. Scripts clássicos em ordem no `index.html`; imagens via `<img>`/`load.image`; áudio via `new Audio()`; dados do mapa embutidos em JS.
- Cada arquivo de `src/logica/` e de `src/` sem Phaser usa o padrão duplo: expõe em `FazOL.<grupo>.<nome>` no navegador e em `module.exports` no Node (ver Task 1).
- Nenhum arquivo pode conter travessão (em dash ou en dash): um hook bloqueia a escrita. Use vírgula, dois-pontos ou ponto.
- Textos do jogo em português do Brasil com acentuação correta.
- Frases dos personagens só entram em `dados/frases.js` com campo `fonte` (URL) preenchido, exceto as marcadas `somenteAudio: true`.
- O jogo **não embute** áudio de ninguém: `audios/` só tem `LEIA-ME.txt`.
- Dica pisca após **10 000 ms** sem jogada. Intervalo mínimo entre falas: **4 000 ms**.
- Pontos: comum 60, especial 120, L 240 (fator 2), obstáculo destruído 300, golpe no chefe 500; tudo × cascata.
- Obras custam **3 ⭐** cada; 3 obras por estado; até **4 ⭐** por fase (3 por pontos + 1 por 3 L's).
- Commits em português, com a linha final `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Testes: `node --test testes/` a partir da raiz do repositório. Sem dependências npm.

## Review Focus

Condições que a spec implica mas que um teste precisa fixar (cada uma tem seu teste na task dona):

1. **Troca que não forma match** deve ser desfeita e **não consumir jogada** (Task 7).
2. **Peça acorrentada** não pode ser trocada nem cair com a gravidade; peças acima dela ficam paradas (Tasks 3 e 4).
3. **Boiada não pode se espalhar para célula com bloco, corrente, especial ou fora da máscara**, e não se espalha na jogada em que alguma boiada foi destruída (Task 6).
4. **Estrela ativada em cadeia** (atingida por outra especial) limpa a cor registrada nela, nunca lança exceção por `pecaAlvo` nulo (Tasks 5 e 7).
5. **`localStorage` indisponível** (lança ao gravar): o progresso segue em memória e `persistente === false` (Task 9).

```js
(function (raiz) {
  'use strict';
  const M = {};

  // mulberry32: rapido, deterministico, bom o bastante para um jogo
  M.criar = function (seed) { return { s: (seed >>> 0) || 0x9e3779b9 }; };

  M.proximo = function (r) {
    r.s = (r.s + 0x6d2b79f5) >>> 0;
    let t = r.s;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };

  M.inteiro = function (r, min, maxExclusivo) {
    return min + Math.floor(M.proximo(r) * (maxExclusivo - min));
  };

  M.escolher = function (r, lista) { return lista[M.inteiro(r, 0, lista.length)]; };

  M.embaralhar = function (r, lista) {
    const a = lista.slice();
    for (let i = a.length - 1; i > 0; i--) {
      const j = M.inteiro(r, 0, i + 1);
      const t = a[i]; a[i] = a[j]; a[j] = t;
    }
    return a;
  };

  if (typeof module !== 'undefined' && module.exports) module.exports = M;
  else { raiz.FazOL = raiz.FazOL || { logica: {}, dados: {}, ui: {} }; raiz.FazOL.logica.rng = M; }
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

function grade(linhas) {
  return linhas.map((linha) => linha.split('').map((ch) => {
    if (ch === '#') return null;
    const cel = matches.novaCelula();
    if (LETRAS[ch]) cel.peca = LETRAS[ch];
    return cel;
  }));
}

function desenhar(celulas) {
  const inv = Object.fromEntries(Object.entries(LETRAS).map(([k, v]) => [v, k]));
  return celulas.map((linha) => linha.map((c) => (c === null ? '#' : c.peca ? inv[c.peca] : '.')).join(''));
}

module.exports = { grade, desenhar, LETRAS };

(function (raiz) {
  'use strict';
  const M = {};

  M.PECAS = ['lula', 'alckmin', 'marina', 'boulos', 'dilma'];

  M.novaCelula = function () { return { peca: null, especial: null, gelatina: 0, corrente: false, bloco: null }; };

  M.chave = function (p) { return p.l + ',' + p.c; };

  M.vizinhos = function (l, c) {
    return [{ l: l - 1, c }, { l: l + 1, c }, { l, c: c - 1 }, { l, c: c + 1 }];
  };

  function pecaEm(celulas, l, c) {
    const linha = celulas[l];
    const x = linha && linha[c];
    return x && x.peca && !x.bloco ? x.peca : null;
  }

  function encontrarRuns(celulas) {
    const L = celulas.length, C = celulas[0].length;
    const runs = [];
    for (let l = 0; l < L; l++) {
      let c = 0;
      while (c < C) {
        const p = pecaEm(celulas, l, c);
        if (!p) { c++; continue; }
        let fim = c;
        while (fim + 1 < C && pecaEm(celulas, l, fim + 1) === p) fim++;
        if (fim - c + 1 >= 3) {
          const cels = [];
          for (let k = c; k <= fim; k++) cels.push({ l, c: k });
          runs.push({ peca: p, dir: 'h', celulas: cels });
        }
        c = fim + 1;
      }
    }
    for (let c = 0; c < C; c++) {
      let l = 0;
      while (l < L) {
        const p = pecaEm(celulas, l, c);
        if (!p) { l++; continue; }
        let fim = l;
        while (fim + 1 < L && pecaEm(celulas, fim + 1, c) === p) fim++;
        if (fim - l + 1 >= 3) {
          const cels = [];
          for (let k = l; k <= fim; k++) cels.push({ l: k, c });
          runs.push({ peca: p, dir: 'v', celulas: cels });
        }
        l = fim + 1;
      }
    }
    return runs;
  }

  function ehPonta(run, cel) {
    const a = run.celulas[0], b = run.celulas[run.celulas.length - 1];
    return (a.l === cel.l && a.c === cel.c) || (b.l === cel.l && b.c === cel.c);
  }

  function meio(run) {
    const m = run.celulas[Math.floor(run.celulas.length / 2)];
    return { l: m.l, c: m.c };
  }

  function classificar(runs) {
    if (runs.some((r) => r.celulas.length >= 5)) return { forma: 'linha5', canto: meio(runs[0]) };
    if (runs.length === 1) {
      const n = runs[0].celulas.length;
      return { forma: n === 4 ? 'linha4' : 'linha3', canto: meio(runs[0]) };
    }
    const hs = runs.filter((r) => r.dir === 'h'), vs = runs.filter((r) => r.dir === 'v');
    for (const h of hs) for (const v of vs) {
      const inter = h.celulas.find((x) => v.celulas.some((y) => y.l === x.l && y.c === x.c));
      if (!inter) continue;
      const forma = ehPonta(h, inter) && ehPonta(v, inter) ? 'L' : 'T';
      return { forma, canto: { l: inter.l, c: inter.c } };
    }
    return { forma: 'T', canto: meio(runs[0]) };
  }

  M.encontrarGrupos = function (celulas) {
    const runs = encontrarRuns(celulas);
    const dono = new Map();
    const grupos = [];
    for (const run of runs) {
      const ids = new Set();
      for (const cel of run.celulas) { const g = dono.get(M.chave(cel)); if (g !== undefined) ids.add(g); }
      let grupo;
      if (ids.size === 0) { grupo = { peca: run.peca, runs: [], celulas: new Map() }; grupos.push(grupo); }
      else {
        const lista = [...ids];
        grupo = grupos[lista[0]];
        for (const outro of lista.slice(1)) {
          const g2 = grupos[outro];
          grupo.runs.push(...g2.runs);
          for (const [k, v] of g2.celulas) grupo.celulas.set(k, v);
          grupos[outro] = null;
        }
      }
      grupo.runs.push(run);
      for (const cel of run.celulas) grupo.celulas.set(M.chave(cel), cel);
      const idx = grupos.indexOf(grupo);
      for (const k of grupo.celulas.keys()) dono.set(k, idx);
    }
    return grupos.filter(Boolean).map((g) => {
      const cls = classificar(g.runs);
      return { peca: g.peca, celulas: [...g.celulas.values()], forma: cls.forma, canto: cls.canto };
    });
  };

  M.podeTrocar = function (celulas, a, b) {
    if (Math.abs(a.l - b.l) + Math.abs(a.c - b.c) !== 1) return false;
    const ca = celulas[a.l] && celulas[a.l][a.c], cb = celulas[b.l] && celulas[b.l][b.c];
    if (!ca || !cb) return false;
    if (!ca.peca || !cb.peca) return false;
    if (ca.bloco || cb.bloco || ca.corrente || cb.corrente) return false;
    return true;
  };

  function trocar(celulas, a, b) {
    const t = celulas[a.l][a.c]; celulas[a.l][a.c] = celulas[b.l][b.c]; celulas[b.l][b.c] = t;
  }

  M.ehJogadaValida = function (celulas, a, b) {
    if (!M.podeTrocar(celulas, a, b)) return false;
    const ca = celulas[a.l][a.c], cb = celulas[b.l][b.c];
    if (ca.especial && cb.especial) return true;
    if (ca.especial === 'estrela' || cb.especial === 'estrela') return true;
    trocar(celulas, a, b);
    const ok = M.encontrarGrupos(celulas).length > 0;
    trocar(celulas, a, b);
    return ok;
  };

  M.encontrarJogada = function (celulas) {
    const L = celulas.length, C = celulas[0].length;
    for (let l = 0; l < L; l++) for (let c = 0; c < C; c++) {
      const a = { l, c };
      for (const b of [{ l, c: c + 1 }, { l: l + 1, c }]) {
        if (b.l >= L || b.c >= C) continue;
        if (M.ehJogadaValida(celulas, a, b)) return { a, b };
      }
    }
    return null;
  };

  M.temJogada = function (celulas) { return M.encontrarJogada(celulas) !== null; };

  if (typeof module !== 'undefined' && module.exports) module.exports = M;
  else { raiz.FazOL = raiz.FazOL || { logica: {}, dados: {}, ui: {} }; raiz.FazOL.logica.matches = M; }
})(typeof globalThis !== 'undefined' ? globalThis : this);

(function (raiz) {
  'use strict';
  const dep = (nome) => (typeof require === 'function' ? require('./' + nome) : raiz.FazOL.logica[nome]);
  const rng = dep('rng');
  const matches = dep('matches');
  const M = {};

  M.criar = function (def, r) {
    const linhas = def.linhas, colunas = def.colunas;
    const mascara = def.mascara || Array.from({ length: linhas }, () => Array(colunas).fill(true));
    const celulas = mascara.map((lin) => lin.map((ok) => (ok ? matches.novaCelula() : null)));
    return {
      linhas, colunas, mascara, celulas,
      pecas: (def.pecas || matches.PECAS).slice(),
      jogadasRestantes: def.jogadas,
      objetivos: def.objetivos.map((o) => Object.assign({}, o, { atual: 0 })),
      limiares: def.limiares.slice(),
      pontos: 0, contadorL: 0, status: 'jogando', rng: r, chefe: null,
    };
  };

  function livre(cel) { return cel && !cel.bloco; }

  M.preencherInicial = function (estado) {
    const { celulas, linhas, colunas, pecas } = estado;
    for (let l = 0; l < linhas; l++) for (let c = 0; c < colunas; c++) {
      const cel = celulas[l][c];
      if (!livre(cel) || cel.peca) continue;
      const proibidas = new Set();
      const e1 = c >= 1 && celulas[l][c - 1], e2 = c >= 2 && celulas[l][c - 2];
      if (e1 && e2 && e1.peca && e1.peca === e2.peca) proibidas.add(e1.peca);
      const n1 = l >= 1 && celulas[l - 1][c], n2 = l >= 2 && celulas[l - 2][c];
      if (n1 && n2 && n1.peca && n1.peca === n2.peca) proibidas.add(n1.peca);
      const opcoes = pecas.filter((p) => !proibidas.has(p));
      cel.peca = rng.escolher(estado.rng, opcoes.length ? opcoes : pecas);
    }
  };

  M.gravidade = function (estado) {
    const { celulas, linhas, colunas } = estado;
    const movimentos = [];
    for (let c = 0; c < colunas; c++) {
      let destino = linhas - 1;
      for (let l = linhas - 1; l >= 0; l--) {
        const cel = celulas[l][c];
        if (!cel || cel.bloco || cel.corrente) { destino = l - 1; continue; }
        if (cel.peca === null) continue;
        if (l !== destino) {
          const alvo = celulas[destino][c];
          alvo.peca = cel.peca; alvo.especial = cel.especial;
          cel.peca = null; cel.especial = null;
          movimentos.push({ de: { l, c }, para: { l: destino, c } });
        }
        destino--;
      }
    }
    return movimentos;
  };

  M.preencher = function (estado) {
    const { celulas, linhas, colunas, pecas } = estado;
    const novas = [];
    for (let c = 0; c < colunas; c++) for (let l = 0; l < linhas; l++) {
      const cel = celulas[l][c];
      if (!livre(cel) || cel.peca !== null) continue;
      cel.peca = rng.escolher(estado.rng, pecas);
      cel.especial = null;
      novas.push({ l, c, peca: cel.peca });
    }
    return novas;
  };

  M.trocar = function (estado, a, b) {
    const ca = estado.celulas[a.l][a.c], cb = estado.celulas[b.l][b.c];
    const p = ca.peca, e = ca.especial;
    ca.peca = cb.peca; ca.especial = cb.especial;
    cb.peca = p; cb.especial = e;
  };

  M.embaralhar = function (estado) {
    const moveis = [];
    estado.celulas.forEach((lin, l) => lin.forEach((cel, c) => {
      if (cel && cel.peca && !cel.bloco && !cel.corrente) moveis.push({ l, c });
    }));
    for (let tentativa = 0; tentativa < 200; tentativa++) {
      const conteudo = rng.embaralhar(estado.rng, moveis.map(({ l, c }) => ({ peca: estado.celulas[l][c].peca, especial: estado.celulas[l][c].especial })));
      moveis.forEach(({ l, c }, i) => { estado.celulas[l][c].peca = conteudo[i].peca; estado.celulas[l][c].especial = conteudo[i].especial; });
      if (matches.encontrarGrupos(estado.celulas).length === 0 && matches.temJogada(estado.celulas)) return true;
    }
    return false;
  };

  M.garantirJogada = function (estado) {
    if (!matches.temJogada(estado.celulas)) M.embaralhar(estado);
  };

  if (typeof module !== 'undefined' && module.exports) module.exports = M;
  else { raiz.FazOL = raiz.FazOL || { logica: {}, dados: {}, ui: {} }; raiz.FazOL.logica.tabuleiro = M; }
})(typeof globalThis !== 'undefined' ? globalThis : this);

    return l >= 0 && l < estado.linhas && c >= 0 && c < estado.colunas && estado.celulas[l][c] !== null;
  }
  function linha(estado, l) {
    const out = [];
    if (l < 0 || l >= estado.linhas) return out;
    for (let c = 0; c < estado.colunas; c++) if (existe(estado, l, c)) out.push({ l, c });
    return out;
  }
  function coluna(estado, c) {
    const out = [];
    if (c < 0 || c >= estado.colunas) return out;
    for (let l = 0; l < estado.linhas; l++) if (existe(estado, l, c)) out.push({ l, c });
    return out;
  }
  function quadrado(estado, l, c, raio) {
    const out = [];
    for (let dl = -raio; dl <= raio; dl++) for (let dc = -raio; dc <= raio; dc++) if (existe(estado, l + dl, c + dc)) out.push({ l: l + dl, c: c + dc });
    return out;
  }

    const out = [];
    estado.celulas.forEach((lin, l) => lin.forEach((cel, c) => { if (cel && !cel.bloco && cel.peca === peca) out.push({ l, c }); }));
    return out;
  }

          estado.chefe = chefe;

            const cc = celulaEm(estado, o.l + dl, o.c + dc);
            if (cc) bloquear(cc, chefe);
          }
          break;
        }
        default: break;
      }
    }
  };

    estado.celulas.forEach((lin) => lin.forEach((cel) => { if (cel && cel.bloco === chefe) cel.bloco = null; }));
  }

    const cel = celulaEm(estado, l, c);
    if (!cel || !cel.bloco) return null;
    const b = cel.bloco;
    forca = forca || 1;
    if (b.tipo === 'chefe') {
      b.vida = Math.max(0, b.vida - forca);
      const destruido = b.vida === 0;
      if (destruido) removerChefe(estado, b);
      return { tipo: 'chefe', destruido, vida: b.vida };
    }
    b.vida -= 1;
    const destruido = b.vida <= 0;
    if (destruido) cel.bloco = null;
    return { tipo: b.tipo, destruido, vida: Math.max(0, b.vida) };
  };

  M.golpeAdjacente = function (estado, l, c) {
    const cel = celulaEm(estado, l, c);
    if (!cel) return null;
    if (cel.corrente) { cel.corrente = false; return { tipo: 'corrente', destruido: true }; }
    if (cel.bloco) return M.golpe(estado, l, c, 1);
    return null;
  };

  function posicoesDeBloco(estado, tipo) {
    const out = [];
    estado.celulas.forEach((lin, l) => lin.forEach((cel, c) => { if (cel && cel.bloco && cel.bloco.tipo === tipo) out.push({ l, c }); }));
    return out;
  }

  function vizinhosLivres(estado, l, c) {
    return matches.vizinhos(l, c).filter((v) => {
      const x = celulaEm(estado, v.l, v.c);
      return x && !x.bloco && !x.corrente && !x.especial && x.peca;
    });
  }

  M.espalharBoiada = function (estado, destruiuBoiada) {
    if (destruiuBoiada) return null;
    const opcoes = [];
    for (const b of posicoesDeBloco(estado, 'boiada')) for (const v of vizinhosLivres(estado, b.l, b.c)) opcoes.push(v);
    if (!opcoes.length) return null;
    const alvo = rng.escolher(estado.rng, opcoes);
    bloquear(celulaEm(estado, alvo.l, alvo.c), { tipo: 'boiada', vida: 1 });
    return { l: alvo.l, c: alvo.c };

  M.avancarFakeNews = function (estado) {
    const novas = [];
    for (const p of posicoesDeBloco(estado, 'fakenews')) {

      b.contador = 0;

      if (!livres.length) continue;
      const alvo = rng.escolher(estado.rng, livres);
      bloquear(celulaEm(estado, alvo.l, alvo.c), { tipo: 'fakenews', vida: 1, contador: 0 });
      novas.push({ l: alvo.l, c: alvo.c, origem: { l: p.l, c: p.c } });
    }
    return novas;
  };

  M.turnoChefe = function (estado) {
    const ch = estado.chefe;
    if (!ch || ch.vida <= 0) return null;
    ch.jogadasAteAtaque -= 1;
    if (ch.jogadasAteAtaque > 0) return null;

    const candidatas = [];
    estado.celulas.forEach((lin, l) => lin.forEach((cel, c) => { if (cel && cel.peca && !cel.bloco && !cel.especial && !cel.corrente) candidatas.push({ l, c, cel }); }));

      alvo.cel.gelatina = Math.min(2, alvo.cel.gelatina + 1);
      return { tipo: 'gelatina', l: alvo.l, c: alvo.c };

    const alvo = rng.escolher(estado.rng, candidatas);
    bloquear(alvo.cel, { tipo: 'fakenews', vida: 1, contador: 0 });
    return { tipo: 'fakenews', l: alvo.l, c: alvo.c };
  };

  const dep = (nome) => (typeof require === 'function' ? require('./' + nome) : raiz.FazOL.logica[nome]);
  const rng = dep('rng');
  const matches = dep('matches');
  const tabuleiro = dep('tabuleiro');

  const M = {};

  function celulaEm(estado, p) { const lin = estado.celulas[p.l]; return lin ? lin[p.c] || null : null; }

  M.iniciarFase = function (def, seed) {
    const s = seed !== undefined ? seed : (def.seed !== undefined ? def.seed : (def.numero || 1));
    const estado = tabuleiro.criar(def, rng.criar(s));
    estado.numero = def.numero;
    estado.def = def;
    obstaculos.colocar(estado, def.obstaculos || []);
    tabuleiro.preencherInicial(estado);
    tabuleiro.garantirJogada(estado);
    atualizarObjetivos(estado);
    return estado;
  };

  // mapa: chave -> {l, c, fator, origem:'match'|'especial'}
  function adicionar(mapa, p, fator, origem) {
    const k = matches.chave(p);
    const atual = mapa.get(k);
    if (!atual) mapa.set(k, { l: p.l, c: p.c, fator, origem });
    else { atual.fator = Math.max(atual.fator, fator); if (origem === 'match') atual.origem = 'match'; }
  }

  // Ativa em cadeia toda especial que esteja em uma célula marcada, somando suas áreas ao mapa.
  function ativarEmCadeia(estado, mapa, eventos) {
    const fila = [...mapa.values()];
    const ativados = new Set();
    while (fila.length) {
      const x = fila.pop();
      const k = matches.chave(x);
      if (ativados.has(k)) continue;
      const cel = celulaEm(estado, x);
      if (!cel || !cel.especial) continue;
      ativados.add(k);
      const esp = cel.especial;
      const area = especiais.areaDeAtivacao(estado, x.l, x.c, esp, cel.peca);
      cel.especial = null;
      if (esp === 'L') estado.contadorL += 1;
      eventos.push({ tipo: 'especialAtivado', especial: esp, l: x.l, c: x.c, peca: cel.peca, celulas: area.celulas });
      for (const y of area.celulas) {
        adicionar(mapa, y, area.fator, 'especial');
        const cy = celulaEm(estado, y);
        if (cy && cy.especial && !ativados.has(matches.chave(y))) fila.push(y);
      }
    }
  }

  function registrarGolpe(estado, obst, r, l, c) {
    obst.push(Object.assign({ l, c }, r));
    if (r.tipo === 'chefe') return pontuacao.PONTOS.chefe;
    if (r.destruido && r.tipo !== 'corrente') return pontuacao.PONTOS.obstaculo;
    return 0;
  }

  function aplicarLimpeza(estado, mapa, eventos, cascata) {
    let pontosRodada = 0, destruiuBoiada = false;
    const limpas = [], obst = [];
    for (const x of mapa.values()) {
      const cel = celulaEm(estado, x);
      if (!cel) continue;
      if (cel.bloco) {
        const r = obstaculos.golpe(estado, x.l, x.c, 1);
        if (r) { pontosRodada += registrarGolpe(estado, obst, r, x.l, x.c); if (r.destruido && r.tipo === 'boiada') destruiuBoiada = true; }
        continue;
      }
      if (cel.peca === null) continue;
      if (cel.gelatina > 0) { cel.gelatina -= 1; obst.push({ tipo: 'gelatina', l: x.l, c: x.c, destruido: cel.gelatina === 0, vida: cel.gelatina }); }
      if (cel.corrente) { cel.corrente = false; obst.push({ tipo: 'corrente', l: x.l, c: x.c, destruido: true }); }
      limpas.push({ l: x.l, c: x.c, peca: cel.peca });
      pontosRodada += x.origem === 'match' ? pontuacao.PONTOS.comum : pontuacao.PONTOS.especial * x.fator;
      for (const o of estado.objetivos) if (o.tipo === 'coletar' && o.peca === cel.peca) o.atual += 1;
      cel.peca = null; cel.especial = null;
    }
    // golpes por adjacência: vizinhos de células limpas por match, uma vez por rodada
    const atingidos = new Set();
    for (const x of mapa.values()) {
      if (x.origem !== 'match') continue;
      for (const v of matches.vizinhos(x.l, x.c)) {
        const kv = matches.chave(v);
        if (mapa.has(kv) || atingidos.has(kv)) continue;
        const cv = celulaEm(estado, v);
        if (!cv || (!cv.bloco && !cv.corrente)) continue;
        const chaveChefe = cv.bloco && cv.bloco.tipo === 'chefe' ? 'chefe' : kv;
        if (atingidos.has(chaveChefe)) continue;
        atingidos.add(kv); atingidos.add(chaveChefe);
        const r = obstaculos.golpeAdjacente(estado, v.l, v.c);
        if (r) { pontosRodada += registrarGolpe(estado, obst, r, v.l, v.c); if (r.destruido && r.tipo === 'boiada') destruiuBoiada = true; }
      }
    }
    const ganho = pontosRodada * cascata;
    estado.pontos += ganho;
    eventos.push({ tipo: 'limpar', celulas: limpas, obstaculos: obst, pontos: ganho, cascata });
    return { destruiuBoiada };
  }

  function assentar(estado, eventos) {
    const mov = tabuleiro.gravidade(estado);
    if (mov.length) eventos.push({ tipo: 'gravidade', movimentos: mov });
    const novas = tabuleiro.preencher(estado);
    if (novas.length) eventos.push({ tipo: 'preencher', novas });
  }

  function resolverCascatas(estado, eventos, grupos, areaInicial, movida, direcao) {
    let cascata = 1, destruiuBoiada = false;
    while (true) {
      const mapa = new Map();
      const criar = [];
      for (const grupo of grupos) {
        const esp = especiais.especialPorForma(grupo.forma, cascata === 1 ? direcao : null, estado.rng);
        let pos = null;
        if (esp) {
          const temMovida = movida && cascata === 1 && grupo.celulas.some((x) => x.l === movida.l && x.c === movida.c);
          pos = temMovida ? { l: movida.l, c: movida.c } : { l: grupo.canto.l, c: grupo.canto.c };
          criar.push({ l: pos.l, c: pos.c, especial: esp, peca: grupo.peca });
        }
        eventos.push({ tipo: 'match', peca: grupo.peca, forma: grupo.forma, tamanho: grupo.celulas.length, celulas: grupo.celulas, cascata, especial: esp, l: pos ? pos.l : undefined, c: pos ? pos.c : undefined });
        for (const cel of grupo.celulas) if (!pos || cel.l !== pos.l || cel.c !== pos.c) adicionar(mapa, cel, 1, 'match');
      }
      if (areaInicial) { for (const cel of areaInicial.celulas) adicionar(mapa, cel, areaInicial.fator, 'especial'); areaInicial = null; }
      ativarEmCadeia(estado, mapa, eventos);
      for (const item of criar) mapa.delete(matches.chave(item));
      const r = aplicarLimpeza(estado, mapa, eventos, cascata);
      destruiuBoiada = destruiuBoiada || r.destruiuBoiada;
      for (const item of criar) {
        const cel = celulaEm(estado, item);
        cel.peca = item.peca; cel.especial = item.especial;
        eventos.push({ tipo: 'especialCriado', especial: item.especial, peca: item.peca, l: item.l, c: item.c });
      }
      assentar(estado, eventos);
      grupos = matches.encontrarGrupos(estado.celulas);
      cascata += 1;
      if (!grupos.length) break;
    }
    return { destruiuBoiada };
  }

  function atualizarObjetivos(estado) {
    const porTipo = { limparGelatina: 'gelatina', limparBoiada: 'boiada', limparFakeNews: 'fakenews', quebrarBlocos: 'bolsonaro', chefe: 'chefe' };
    for (const o of estado.objetivos) {
      if (o.tipo === 'pontos') o.atual = estado.pontos;
      else if (porTipo[o.tipo]) o.atual = Math.max(0, o.alvo - obstaculos.contar(estado, porTipo[o.tipo]));
    }
  }

  M.objetivosCumpridos = function (estado) { return estado.objetivos.every((o) => o.atual >= o.alvo); };

  function bonusFinal(estado, eventos) {
    let n = Math.min(estado.jogadasRestantes, 10);
    while (n-- > 0) {
      const cand = [];
      estado.celulas.forEach((lin, l) => lin.forEach((cel, c) => { if (cel && cel.peca && !cel.especial && !cel.bloco && !cel.corrente) cand.push({ l, c }); }));
      if (!cand.length) break;
      const p = rng.escolher(estado.rng, cand);
      const esp = rng.proximo(estado.rng) < 0.5 ? 'listradaH' : 'listradaV';
      celulaEm(estado, p).especial = esp;
      eventos.push({ tipo: 'bonusJogada', l: p.l, c: p.c, especial: esp });
      const mapa = new Map();
      adicionar(mapa, p, 1, 'especial');
      ativarEmCadeia(estado, mapa, eventos);
      aplicarLimpeza(estado, mapa, eventos, 1);
      assentar(estado, eventos);
    }
    estado.jogadasRestantes = 0;
  }

  M.jogar = function (estado, a, b) {
    const eventos = [];
    if (estado.status !== 'jogando') return { valido: false, eventos };
    if (!matches.podeTrocar(estado.celulas, a, b)) return { valido: false, eventos };
    tabuleiro.trocar(estado, a, b);
    const movida = { l: b.l, c: b.c }, outra = { l: a.l, c: a.c };
    const celMovida = celulaEm(estado, movida), celOutra = celulaEm(estado, outra);
    const direcao = a.l === b.l ? 'h' : 'v';
    let grupos = [], areaInicial = null;

    if (celMovida.especial && celOutra.especial) {
      const tipo = especiais.tipoDeCombo(celMovida.especial, celOutra.especial);
      const naoEstrela = celMovida.especial === 'estrela' ? celOutra : celMovida;
      areaInicial = especiais.areaDoCombo(estado, outra, movida, tipo, naoEstrela.peca, naoEstrela.especial);
      estado.contadorL += [celMovida, celOutra].filter((x) => x.especial === 'L').length;
      eventos.push({ tipo: 'troca', a, b });
      eventos.push({ tipo: 'combo', combo: tipo, a: outra, b: movida, especiais: [celOutra.especial, celMovida.especial], peca: naoEstrela.peca, celulas: areaInicial.celulas });
      celMovida.especial = null; celOutra.especial = null;
    } else if (celMovida.especial === 'estrela' || celOutra.especial === 'estrela') {
      const posEstrela = celMovida.especial === 'estrela' ? movida : outra;
      const alvo = celMovida.especial === 'estrela' ? celOutra : celMovida;
      areaInicial = especiais.areaDeAtivacao(estado, posEstrela.l, posEstrela.c, 'estrela', alvo.peca);
      celulaEm(estado, posEstrela).especial = null;
      eventos.push({ tipo: 'troca', a, b });
      eventos.push({ tipo: 'especialAtivado', especial: 'estrela', l: posEstrela.l, c: posEstrela.c, peca: alvo.peca, celulas: areaInicial.celulas });
    } else {
      grupos = matches.encontrarGrupos(estado.celulas);
      if (!grupos.length) {
        tabuleiro.trocar(estado, a, b);
        eventos.push({ tipo: 'trocaInvalida', a, b });
        return { valido: false, eventos };
      }
      eventos.push({ tipo: 'troca', a, b });
    }

    estado.jogadasRestantes -= 1;
    const { destruiuBoiada } = resolverCascatas(estado, eventos, grupos, areaInicial, movida, direcao);

    const boi = obstaculos.espalharBoiada(estado, destruiuBoiada);
    if (boi) eventos.push({ tipo: 'boiadaEspalhou', l: boi.l, c: boi.c });
    for (const f of obstaculos.avancarFakeNews(estado)) eventos.push({ tipo: 'fakeNewsMultiplicou', l: f.l, c: f.c, origem: f.origem });
    const ataque = obstaculos.turnoChefe(estado);
    if (ataque) eventos.push({ tipo: 'chefeAtacou', ataque: ataque.tipo, l: ataque.l, c: ataque.c });

    atualizarObjetivos(estado);
    if (M.objetivosCumpridos(estado)) {
      estado.status = 'vitoria';
      bonusFinal(estado, eventos);
      atualizarObjetivos(estado);
    } else if (estado.jogadasRestantes <= 0) {
      estado.status = 'derrota';
    } else if (!matches.temJogada(estado.celulas)) {
      tabuleiro.embaralhar(estado);
      eventos.push({ tipo: 'embaralhar' });
    }
    eventos.push({ tipo: 'fim', status: estado.status, pontos: estado.pontos, jogadasRestantes: estado.jogadasRestantes, estrelas: M.estrelas(estado) });
    return { valido: true, eventos };
  };

  M.estrelas = function (estado) {
    return pontuacao.estrelas(estado.pontos, estado.limiares, estado.contadorL, estado.status === 'vitoria');
  };

  if (typeof module !== 'undefined' && module.exports) module.exports = M;
  else { raiz.FazOL = raiz.FazOL || { logica: {}, dados: {}, ui: {} }; raiz.FazOL.logica.turno = M; }
})(typeof globalThis !== 'undefined' ? globalThis : this);

(function (raiz) {
  'use strict';
  const dep = (nome) => (typeof require === 'function' ? require('./' + nome) : raiz.FazOL.logica[nome]);
  const rng = dep('rng');
  const matches = dep('matches');
  const estados = typeof require === 'function' ? require('../../dados/estados') : raiz.FazOL.dados.estados;
  const fases = typeof require === 'function' ? require('../../dados/fases') : raiz.FazOL.dados.fases;
  const M = {};

  M.TOTAL_FASES = estados.TOTAL_FASES;
  const DESBLOQUEIO = { gelatina: 5, fakenews: 12, corrente: 20, bolsonaro: 30, boiada: 45 };
  const MAXIMOS = { gelatina: 99, fakenews: 3, corrente: 4, bolsonaro: 4, boiada: 3 };
  const arred100 = (x) => Math.max(100, Math.round(x / 100) * 100);

  function clonar(x) { return JSON.parse(JSON.stringify(x)); }

  function escolherMascara(r, tam) {
    const tipo = rng.escolher(r, ['cantos', 'L', 'cruz']);
    return Array.from({ length: tam }, (_, l) => Array.from({ length: tam }, (_, c) => {
      const ult = tam - 1;
      if (tipo === 'cantos') return !((l === 0 || l === ult) && (c === 0 || c === ult));
      if (tipo === 'L') return c < 3 || l >= tam - 3;
      return !((l < 2 || l > ult - 2) && (c < 2 || c > ult - 2));
    }));
  }

  function gerar(n) {
    const r = rng.criar(n * 7919 + 17);
    const uf = estados.estadoDaFase(n);
    const d = Math.min(1, Math.max(0, (n - 10) / (M.TOTAL_FASES - 10)));
    const respiro = n % 5 === 0;
    const chefe = estados.ehFaseDeChefe(n);
    const tam = n > 50 ? 9 : 8;
    const def = { numero: n, estado: uf.sigla, seed: n, linhas: tam, colunas: tam, pecas: respiro ? matches.PECAS.slice(0, 4) : matches.PECAS.slice(), obstaculos: [], objetivos: [], dica: null };
    if (!chefe && rng.proximo(r) < 0.2) def.mascara = escolherMascara(r, tam);

    const ocupadas = new Set();
    const livre = (l, c) => (!def.mascara || def.mascara[l][c]) && !ocupadas.has(l + ',' + c);
    const posAleatoria = () => {
      for (let t = 0; t < 200; t++) { const l = rng.inteiro(r, 0, tam), c = rng.inteiro(r, 0, tam); if (livre(l, c)) { ocupadas.add(l + ',' + c); return { l, c }; } }
      return null;
    };

    if (chefe) {
      const vida = 8 + Math.round(6 * d);
      const c0 = Math.floor(tam / 2) - 1;
      for (let dl = 0; dl <= 1; dl++) for (let dc = 0; dc <= 1; dc++) ocupadas.add(dl + ',' + (c0 + dc));
      def.obstaculos.push({ tipo: 'chefe', l: 0, c: c0, vida });
      def.objetivos.push({ tipo: 'chefe', alvo: vida });
      def.dica = 'Chefe: Flávio. Faça matches encostados no bloco 2x2 para derrubar a vida dele. Especiais também acertam.';
    }

    const desbloqueados = Object.keys(DESBLOQUEIO).filter((t) => n >= DESBLOQUEIO[t]);
    const contagem = {};
    if (desbloqueados.length) {
      const tipos = rng.embaralhar(r, desbloqueados).slice(0, n > 25 ? 2 : 1);
      let qtd = Math.round((4 + 10 * d) * (respiro ? 0.5 : 1));
      if (chefe) qtd = Math.round(qtd / 2);
      for (let i = 0; i < qtd; i++) {
        let tipo = tipos[i % tipos.length];
        if ((contagem[tipo] || 0) >= MAXIMOS[tipo]) tipo = 'gelatina';
        const p = posAleatoria();
        if (!p) break;
        const o = { tipo, l: p.l, c: p.c };
        if (tipo === 'gelatina' && d > 0.4 && rng.proximo(r) < 0.3) o.camadas = 2;
        def.obstaculos.push(o);
        contagem[tipo] = (contagem[tipo] || 0) + 1;
      }
    }

    if (!chefe) {
      const opcoes = [];
      if (contagem.gelatina) opcoes.push('limparGelatina');
      if (contagem.boiada) opcoes.push('limparBoiada');
      if (contagem.fakenews) opcoes.push('limparFakeNews');
      if (contagem.bolsonaro) opcoes.push('quebrarBlocos');
      const deObstaculo = opcoes.slice();
      opcoes.push('pontos', 'coletar');
      const quantos = n > 25 && !respiro ? 2 : 1;
      const escolhidos = [];
      if (deObstaculo.length) escolhidos.push(rng.escolher(r, deObstaculo));
      for (const t of rng.embaralhar(r, opcoes)) { if (escolhidos.length >= quantos) break; if (!escolhidos.includes(t)) escolhidos.push(t); }
      for (const tipo of escolhidos) {
        if (tipo === 'pontos') def.objetivos.push({ tipo, alvo: arred100(2500 + 9000 * d) });
        else if (tipo === 'coletar') def.objetivos.push({ tipo, peca: rng.escolher(r, def.pecas), alvo: 15 + Math.round(25 * d) });
        else if (tipo === 'limparGelatina') def.objetivos.push({ tipo, alvo: def.obstaculos.filter((o) => o.tipo === 'gelatina').reduce((s, o) => s + (o.camadas || 1), 0) });
        else if (tipo === 'limparBoiada') def.objetivos.push({ tipo, alvo: contagem.boiada });
        else if (tipo === 'limparFakeNews') def.objetivos.push({ tipo, alvo: contagem.fakenews });
        else if (tipo === 'quebrarBlocos') def.objetivos.push({ tipo, alvo: contagem.bolsonaro });
      }
    }

    def.jogadas = Math.round(30 - 12 * d) + (respiro ? 5 : 0) + (def.objetivos.length === 2 ? 5 : 0) + (chefe ? 5 : 0);
    const objPontos = def.objetivos.find((o) => o.tipo === 'pontos');
    const base = objPontos ? objPontos.alvo : arred100(def.jogadas * 250 * (1 + d));
    def.limiares = [base, arred100(base * 1.6), arred100(base * 2.4)];
    return def;
  }

  M.obterFase = function (n) {
    const manual = fases.manuais.find((f) => f.numero === n);
    if (manual) {
      const def = clonar(manual);
      def.estado = estados.estadoDaFase(n).sigla;
      def.seed = n;
      return def;
    }
    if (n < 1 || n > M.TOTAL_FASES) return null;
    return gerar(n);
  };

  if (typeof module !== 'undefined' && module.exports) module.exports = M;
  else { raiz.FazOL = raiz.FazOL || { logica: {}, dados: {}, ui: {} }; raiz.FazOL.logica.geradorFases = M; }
})(typeof globalThis !== 'undefined' ? globalThis : this);

  'use strict';
  const M = {};

  M.criar = function (opts) {
    const frases = opts.frases || [];
    const nomes = opts.nomes || {};
    const criarAudio = opts.criarAudio || null;
    const sintetizar = opts.sintetizar || null;
    const aoBalao = opts.aoBalao || function () {};
    const agora = opts.agora || (() => Date.now());
    const agendar = opts.agendar || ((fn, ms) => setTimeout(fn, ms));
    const aleatorio = opts.aleatorio || Math.random;
    const intervalo = opts.intervaloMs || 4000;
    const pasta = opts.pastaAudios || 'audios/';

    const estado = { mudo: false, volume: 0.8, ultimaFala: -Infinity, pendente: null, timerAtivo: false, rotacao: {}, historico: [] };

    function embaralhar(lista) {
      const a = lista.slice();
      for (let i = a.length - 1; i > 0; i--) { const j = Math.floor(aleatorio() * (i + 1)); const t = a[i]; a[i] = a[j]; a[j] = t; }
      return a;
    }
    const gatilhosDe = (f) => f.gatilhos || ['match'];

    function escolherFrase(personagem, gatilho) {
      const g = gatilho || 'match';
      let cand = frases.filter((f) => f.personagem === personagem && gatilhosDe(f).includes(g));
      if (!cand.length && g !== 'match') cand = frases.filter((f) => f.personagem === personagem && gatilhosDe(f).includes('match'));
      if (!cand.length) cand = frases.filter((f) => f.personagem === personagem);
      if (!cand.length) return null;
      const k = personagem + '|' + g;
      let fila = estado.rotacao[k];
      if (!fila || !fila.length) fila = estado.rotacao[k] = embaralhar(cand.map((f) => f.id));
      const id = fila.shift();
      return cand.find((f) => f.id === id) || cand[0];
    }

    function executar(item) {
      estado.ultimaFala = agora();
      estado.historico.push(item);
      const frase = item.frase;
      aoBalao({ personagem: item.personagem, nome: nomes[item.personagem] || item.personagem, texto: frase && frase.texto ? frase.texto : '' });
      if (estado.mudo || !frase) return;
      let caiu = false;
      const fallback = () => {
        if (caiu) return;
        caiu = true;
        if (!frase.somenteAudio && frase.texto && sintetizar) sintetizar(frase.texto, estado.volume);
      };
      if (!criarAudio) { fallback(); return; }
      let audio;
      try { audio = criarAudio(pasta + frase.id + '.mp3'); } catch (e) { fallback(); return; }
      try { audio.volume = estado.volume; } catch (e) { /* ignora */ }
      audio.onerror = fallback;
      try {
        const p = audio.play();
        if (p && typeof p.catch === 'function') p.catch(fallback);
      } catch (e) { fallback(); }
    }

      estado.timerAtivo = false;
      if (!estado.pendente) return;
      const falta = estado.ultimaFala + intervalo - agora();
      if (falta > 0) { estado.timerAtivo = true; agendar(processar, falta); return; }
      const item = estado.pendente;
      estado.pendente = null;
      executar(item);

      if (t - estado.ultimaFala >= intervalo && !estado.pendente) { executar(item); return; }

function baixar(url, destino, tentativas) {
  return new Promise((resolve, reject) => {
    https.get(url, (r) => {
      if ([301, 302, 307, 308].includes(r.statusCode) && r.headers.location && tentativas > 0) {
        r.resume();
        return baixar(r.headers.location, destino, tentativas - 1).then(resolve, reject);
      }
      if (r.statusCode !== 200) return reject(new Error('HTTP ' + r.statusCode + ' ao baixar ' + url));
      const f = fs.createWriteStream(destino);
      r.pipe(f);
      f.on('finish', () => f.close(resolve));
      f.on('error', reject);
    }).on('error', reject);
  });
}

function distanciaAoSegmento(p, a, b) {
  const dx = b[0] - a[0], dy = b[1] - a[1];
  if (dx === 0 && dy === 0) return Math.hypot(p[0] - a[0], p[1] - a[1]);
  let t = ((p[0] - a[0]) * dx + (p[1] - a[1]) * dy) / (dx * dx + dy * dy);
  t = Math.max(0, Math.min(1, t));
  return Math.hypot(p[0] - (a[0] + t * dx), p[1] - (a[1] + t * dy));
}

// Douglas-Peucker iterativo
function simplificar(pontos, tol) {
  if (pontos.length < 3) return pontos;
  const manter = new Array(pontos.length).fill(false);
  manter[0] = manter[pontos.length - 1] = true;
  const pilha = [[0, pontos.length - 1]];
  while (pilha.length) {
    const [i0, i1] = pilha.pop();
    let maxD = 0, idx = -1;
    for (let i = i0 + 1; i < i1; i++) {
      const d = distanciaAoSegmento(pontos[i], pontos[i0], pontos[i1]);
      if (d > maxD) { maxD = d; idx = i; }
    }
    if (maxD > tol && idx > 0) { manter[idx] = true; pilha.push([i0, idx], [idx, i1]); }
  }
  return pontos.filter((_, i) => manter[i]);
}

function aneis(geometria) {
  if (geometria.type === 'Polygon') return geometria.coordinates;
  if (geometria.type === 'MultiPolygon') return geometria.coordinates.flat();
  return [];
}

function centroide(anel) {
  let a = 0, cx = 0, cy = 0;
  for (let i = 0; i < anel.length - 1; i++) {
    const [x0, y0] = anel[i], [x1, y1] = anel[i + 1];
    const f = x0 * y1 - x1 * y0;
    a += f; cx += (x0 + x1) * f; cy += (y0 + y1) * f;
  }
  if (Math.abs(a) < 1e-9) return anel[0];
  a *= 0.5;
  return [cx / (6 * a), cy / (6 * a)];
}

    function selecionar(sigla) { selecionado = sigla; renderPainel(); }

    montar();
    return {

  };

  if (typeof module !== 'undefined' && module.exports) module.exports = M;
